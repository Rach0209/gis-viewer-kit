# 07. Cesium 시험 제작(스파이크) 결과

날짜: 2026-11-05. 코드: 공개 저장소에서는 뺐다(정식 코드가 아닌 실험이었고, 그 결과를 `gis/`가 이어받았다). 이 문서는 시험 경과 기록으로만 남긴다.
결정 배경: GIS 업무용으로 glb/GeoJSON/SHP를 여러 개 겹쳐 보고 싶다 → three.js만으로는 벡터·좌표·지형을 직접 다 만들어야 해서, **Cesium 별도 페이지**를 시험했다 (사용자 결정: 별도 페이지면 충분, ion 미사용, 배경은 OSM/VWorld만).

## 결론 한 줄
확인하려던 네 가지가 모두 **된다.** Cesium을 GIS용 별도 페이지로 만드는 방향이 타당하다. 다만 아래 "남은 위험"을 정식 제작 중에 확인해야 한다.

## 확인 결과

| 확인할 것 | 결과 | 근거 |
|---|---|---|
| ion 없이 뜨는가 | ✅ | Cesium 1.147.0, 배경은 OSM(`UrlTemplateImageryProvider`). 네트워크에 `cesium.com`/ion 요청 0건. 지오코더·지도 선택기는 ion을 쓰므로 껐다 |
| 로컬 폴더 3D Tiles (서버 없이) | ✅ | 가짜 주소(`http://local-files.invalid/<n>/…`)를 `Cesium.Resource._Implementations.loadWithXhr`에서 가로채 `File`에서 읽는다. 실데이터(1GB, Draco+KTX2 glb)가 열렸고 타일 로드 실패 0건, 파일 98개를 이 경로로 읽음. 건물이 OSM 도로 위에 맞게 놓임 |
| glb를 경위도에 배치 + 지도 클릭 배치 | ✅ | 지도를 클릭하면 그 지점의 경위도에 배치됨. Draco+KTX2 glb가 192ms에 준비 |
| GeoJSON / SHP가 맞는 위치에 | ✅ | EPSG:5179 점·면과 5186 선, 4326 GeoJSON이 기준값 대비 **오차 0.00m**(500m 떨어진 점은 정확히 500m). `.prj`만 보고 변환됨 |

## 이번 시험에서 새로 알게 된 것 (정식 제작에 반영)

1. **한글 SHP 속성 인코딩 (중요).** `shpjs`는 `.cpg`가 `EUC-KR` 또는 `949`일 때만 한글을 제대로 읽는다. 한국 데이터에서 가장 흔한 **`CP949`와, `.cpg`가 없는 경우는 깨진다** (기본이 UTF-8). → `.cpg` 값을 정규화(`CP949`/`949` → `EUC-KR`)하고, 없으면 UTF-8로 엄격하게 시도해 보고 실패하면 EUC-KR로 읽으며, **사용자가 인코딩을 고르는 선택칸**을 둬야 한다.
2. **좌표계는 `.prj`가 있으면 자동으로 맞는다.** ESRI WKT(5179, 5186)를 proj4가 해석했다. `.prj`가 없거나 옛 좌표계(5174 등)면 사용자 선택이 필요하다 (이번 시험에서는 `.prj` 있는 경우만 확인).
3. **Cesium은 `.js`를 일반 스크립트로 읽어야 한다.** Vite 개발 서버가 `node_modules`의 Cesium을 변환해 깨뜨리므로 `public/`(변환 없이 서빙)에 둔다. 시험에서는 `public/cesium`을 디렉터리 정션으로 연결했다 (git 제외).
4. 기본 로고가 "Cesium ion"으로 표시된다. 출처 표시는 유지해야 한다 (끄지 않는다).
5. 확인용 브라우저 창이 가려지면 렌더링이 느려져서, 시험은 프레임을 직접 그려 가며 진행했다. 실제 사용 속도와는 다르다.

## 남은 위험 (이번에 확인하지 못함)

- **비공개(private) API 의존:** 로컬 폴더 읽기는 `Cesium.Resource._Implementations.loadWithXhr`(밑줄로 시작하는 내부 함수)를 교체하는 방식이다. Cesium 버전이 바뀌면 깨질 수 있다. 버전을 고정하고 시험으로 지키거나, 대안(파일 주소를 Blob URL로 바꾸는 방식, 서비스 워커)을 준비한다.
- **실제 폴더 선택창:** 시험은 서버의 파일을 "로컬 파일처럼" 읽게 한 것이다. 운영체제 폴더 선택창(`showDirectoryPicker`)으로 실제 폴더를 여는 동작은 이 환경에서 못 해 봤다 (버튼은 만들어 두었다).
- **지형(DEM):** ion 없이는 기본 지형이 없다(평평한 타원체). 무료 지형 공급원을 쓸지 정해야 한다. 지형이 없으면 벡터를 "지면에 붙이는" 효과도 평평한 곳에서만 의미가 있다.
- **3D 타일 위에 벡터 붙이기(분류):** 코드는 넣었지만 화면으로 확인하지 못했다.
- **VWorld 실타일:** API 키가 없어 못 받아 봤다.
- **한글 속성 인코딩 실제 데이터:** EUC-KR `.dbf`는 직접 만든 시험 파일로만 확인했다. 실제 한국 데이터 몇 개로 확인해야 한다.
- **실제 GPU 성능, 큰 SHP/GeoJSON 성능:** 측정하지 않았다.

## 그 뒤

이 시험 코드는 공개 저장소에서 뺐다. 시험에서 확인한 방법(가짜 주소로 로컬 폴더 읽기, 인코딩·좌표계 처리 등)은 모두 `gis/`로 옮겨 정식으로 구현했고, 그 내용은 [09-gis-page.md](09-gis-page.md)에 있다.
