# 08. 단독 glb 직접 시험해 보기

대상: 뷰어(three.js 페이지)의 "glb 열기" 기능 (P8a). 시험용 파일은 가짜 "집" 모양(몸체 + 한쪽 모서리의 높은 탑)이라서, 방향·위쪽 축·배율을 바꾸면 달라지는 것이 눈에 보인다.

## 준비

```bash
cd viewer
node tools/make-sample-glbs.mjs     # ../samples/glb/ 에 시험 파일 4개 생성 (이미 만들어 두었음)
npm run dev                          # http://localhost:5173
```

브라우저에서 **`http://localhost:5173/kit-demo.html`** 을 연다. (`samples/`는 git에 올라가지 않는다.)
실제 타일셋도 같이 보려면 `kit-demo.html?url=/tiles-real/tileset.json&errorTarget=32&fade=0`.

## 시험 파일 (`samples/glb/`)

| 파일 | 무엇을 시험하나 |
|---|---|
| `1_house_local.glb` | 좌표 없는 일반 모델 (Y가 위, 미터) |
| `2_house_zup.glb` | Z가 위인 모델 → **위쪽 축**을 바꿔야 바로 선다 |
| `3_house_with_position.glb` | 파일 안에 위치(CESIUM_RTC)가 있는 모델 → **자동 판별** |
| `5_house_embedded_5186.glb` | 파일 안에 실제 투영 좌표(EPSG:5186)가 든 모델 → **추천 + 좌표계 선택칸** (서울 시청 부근, 선택칸을 동부원점으로 바꾸면 경도가 +2도, 지도 핀이 동해 쪽으로 이동) |
| `4_house_mm_units.glb` | 단위가 mm라 1000배 큰 모델 → **크기 배율** |

## 시험 순서와 기대 결과

1. **지도에서 클릭해서 배치 (기본 방법)** — 툴바 `glb 열기` → `1_house_local.glb`.
   - "glb 위치 정하기" 대화상자 안에 **지도**가 뜬다(처음엔 한국 전체).
   - 지도를 **끌어서 이동**, **휠**(또는 오른쪽 위 `+` `−`)로 확대해서 원하는 건물 위치까지 간 다음 **클릭**한다.
   - 기대: 클릭한 곳에 빨간 **핀**이 꽂히고, 아래 `X`/`Y`칸이 자동으로 채워지며 `경도 …, 위도 …`가 나온다 → `이 위치에 배치`.
   - 기대: 집이 화면에 나오고, 오른쪽 정보 패널에 입력 좌표계·X·Y·경도/위도가 보인다. 나침반이 보인다.
   - **배경 지도(OpenStreetMap)는 자동으로 깔린다.** 끄고 싶으면 왼쪽 `레이어` → `배경 지도`를 `쓰지 않음`으로 (한 번 끄면 이후 glb에서도 자동으로 켜지 않는다). 좌표 없는 "단일 모델"에는 지도가 없다.
   - 같은 파일을 다시 열면 지도가 **지난번에 고른 위치에서** 시작한다.
1-1. **좌표를 알고 있을 때** — 같은 대화상자에서 좌표계(기본 `UTM-K EPSG:5179`)를 두고 X `953901.17`, Y `1952032.08`를 입력하면 `경도 126.978, 위도 37.5665`이 나오고 **지도의 핀이 그 위치로 따라 움직인다**. 지도로 위치를 고른 뒤 좌표계를 바꾸면 같은 지점의 값이 새 좌표계 값으로 바뀐다.
2. **방향** — 같은 파일을 다시 열어(지도에서 위치를 고르고) 방향 `90` → 높은 탑이 북서쪽 모서리에서 **시계 방향으로 돌아** 북동쪽으로 간다 (위에서 볼 때).
3. **좌표계를 잘못 골랐을 때** — 좌표계를 `WGS84 경위도`로 바꾸고 1-1번의 5179 값을 넣으면 "경위도 범위를 벗어났습니다. 좌표계를 확인하세요"가 나온다.
4. **위쪽 축** — `2_house_zup.glb`를 열어 위쪽 축 `Y`로 배치하면 **누워 보이고**, `Z`로 하면 **바로 선다**.
5. **자동 판별** — `3_house_with_position.glb`를 열면 대화상자 맨 위에 초록 상자("파일에서 위치 정보를 찾았습니다")가 있다 → `이 위치로 배치` → 1-1번(좌표 입력)과 같은 위치(126.978 / 37.5665)에 놓인다.
6. **단위(배율)** — `4_house_mm_units.glb`: 대화상자에 "단위가 mm/cm라면 크기 배율을 줄여 보세요" 경고. 배율 `1`이면 거대하고, `0.001`이면 약 30m 집이 된다.
7. **단일 모델 보기 (동의)** — 아무 파일을 열고 `좌표 없이 단일 모델로 보기`를 누른다.
   - 기대: 지도·나침반·좌표 표시 없이 모델만 보이고(드래그로 회전), `레이어` 패널의 배경 지도는 비활성 + 안내 문구. **이 버튼을 누르기 전에는 열리지 않는다.**
8. **취소** — 대화상자에서 `취소` 또는 Esc → 이전 화면이 그대로 남는다.
9. **끌어놓기** — 탐색기에서 glb 파일을 뷰어 화면에 끌어다 놓는다 → 같은 대화상자. (폴더를 놓으면 타일셋으로 열린다.)
10. **기능 확인** — 모델을 연 뒤 `거리재기`, `메모 추가`, 마우스를 올려 강조, 클릭 시 좌표 정보, `체험(걷기)`, `미니맵`이 동작하는지.
11. **교체 확인** — 메모를 하나 남긴 뒤 다른 glb(또는 타일셋)를 열면 "메모 N개가 삭제됩니다" 확인창이 뜬다. `취소`면 유지.

## 직접 가진 glb로 시험할 때 보면 좋은 것
- **크기/위치가 이상할 때**: 대화상자의 경고 문구와 정보 패널의 "대략 크기"를 먼저 본다. 단위가 mm/cm/km면 배율, 눕거나 뒤집히면 위쪽 축.
- **압축 파일**: 정보 패널 "압축 / 디코더"에 Draco/KTX2가 `필요 · 디코드 가능`으로 나오는지.
- **파일 안에 실제 좌표가 든 모델(DT용 등)**: 대화상자에 "파일에서 위치 정보를 찾았습니다 → Korea 2000 중부원점(EPSG:5186) 좌표로 읽기 …" 추천이 뜬다. `이 위치로 배치`를 누르면 지도의 그 위치에 바닥 중심이 놓인다. 좌표가 없는 일반 glb에서는 이 추천이 나오지 않는다. 대화상자 맨 아래 `파일 단위: m / cm / mm` 버튼으로 배율을 빠르게 맞출 수 있다.
- **자동 판별이 틀릴 때**: 대화상자 아래 "좌표 입력"에서 직접 넣으면 된다.
- **높이가 어긋날 때**: 높이는 **타원체고** 기준이다. 한국에서는 표고(해발고)와 수십 m 차이가 날 수 있으니 높이 값을 조정한다.

## 이 환경에서 못 해 본 것 (직접 확인 부탁)
- `glb 열기` 버튼을 눌렀을 때의 **운영체제 파일 선택창**
- **실제 GIS glb** (좌표 있는 것/없는 것), 특히 자동 판별
- 모델 위에서 **체험(걷기)으로 실제 걷기** (포인터 락)

## 배치한 뒤 고치기 (모델 편집)
모델을 연 뒤 툴바의 **`모델 편집`** 버튼을 누르면 왼쪽에 편집 패널이 열린다. 바꾸는 즉시 화면에 반영된다.

1. **동서남북 이동** — `이동 단위`를 `10 m`로 두고 ▲를 눌러 본다 → 모델이 북쪽으로 10 m씩 간다. (오른쪽 정보 패널의 경도/위도가 바뀐다.)
2. **모델을 끌어서 이동** — 버튼을 켜고(파랗게 됨) 화면의 **모델을 마우스로 끌면** 따라 움직인다. 모델 **밖**을 끌면 지도(카메라)만 이동한다. 거리재기/메모/체험을 켜면 이 모드는 자동으로 꺼진다.
3. **지도에서 다시 선택** — 작은 지도 대화상자에서 새 위치를 클릭 → `이 위치로 이동`. 멀리(80 m 이상) 옮기면 배경 지도도 새 위치로 다시 깔린다.
4. **높이** — `+`/`−`(이동 단위만큼) 또는 숫자 입력. 건물이 지도 위에 뜨거나 파묻히면 맞춘다.
5. **방향** — 슬라이더, 숫자, `−15° −1° +1° +15°`. 위에서 볼 때 **시계 방향**.
6. **기울기** — 앞뒤(+면 북쪽이 올라감), 좌우(+면 동쪽이 올라감). 경사지에 놓거나 모델이 약간 기울어 있을 때.
7. **크기 배율**, 그리고 틀렸을 때 **`처음 값으로`**.
- 좌표 없이 "단일 모델로 보기"를 고른 경우에는 위치·높이 칸이 없고 방향·기울기·크기만 있다.
- 미니맵은 glb를 열면 **기본으로 꺼져** 있다 (필요하면 툴바 `미니맵`으로 켠다).
