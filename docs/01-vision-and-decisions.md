# 01. 목적, 범위, 결정 사항

작성일: 2026-11-04

## 1. 한 줄 목적
**클라이언트가 자신의 3D Tiles 타일셋을 웹에서 직접 열어 뷰어 기능(측정, 메모, 걷기 체험, 미니맵 등)을 테스트해 볼 수 있게 한다.**

## 2. 두 가지 사용 방식

| | A. 로컬 파일 모드 (주 목적) | B. 백엔드 데모 모드 (시연용) |
|---|---|---|
| 목적 | 고객 데이터로 즉시 확인 | "백엔드와 연결하면 실제 프로젝트에도 적용된다"는 확신 제공 |
| 타일 | 사용자 PC 폴더를 브라우저가 직접 읽음 | Java 서버가 폴더를 서빙 |
| 백엔드 | 없음 | Java (로컬 → 이후 클라우드) |
| 데이터 이동 | 업로드 없음 | 서버 → 브라우저 |

두 방식은 **같은 뷰어 코드**를 쓰고, 타일을 어디서 가져오는지(`TilesetSource`)만 다르다 ([03-viewer-api.md](03-viewer-api.md)).

## 3. 범위

### 포함
- `<script>` 태그로 임베드하는 JS 번들 (ES 모듈 / IIFE 동시 제공)
- 로컬 폴더 선택·드래그앤드롭으로 타일셋 열기 (백엔드 불필요)
- 타일셋 모드 자동 판별(model/geo)과 기준 원점 자동 계산
- Java 백엔드: 타일셋 목록 API + 타일 파일 서빙 (로컬 실행 우선)
- npm 패키지 (스크립트 번들 이후)

### 제외 (현재 시점)
- **iframe 방식 임베드** — 사용하지 않기로 함
- **서버 업로드(zip 업로드 등)** — 주 목적이 아니므로 보류. 필요해지면 클라우드 단계에서 재검토
- 서버 측 타일 변환/압축 해제 — 하지 않음 (Draco/KTX2는 브라우저에서 해제)
- 인증/권한 — 로컬 데모 단계에서는 없음
- 클라우드 배포 — 로컬 완성 후 이관

## 4. 확정된 결정

| # | 결정 | 이유 |
|---|---|---|
| D1 | 주 목적은 "사용자 자신의 타일셋을 직접 열어 테스트" | 사용자 요구 |
| D2 | Java 백엔드는 **시연/통합 확인용**. 로컬 파일 모드는 백엔드 없이 동작해야 함 | 설치·권한 장벽 최소화 |
| D3 | 로컬에서 먼저 개발하고 클라우드는 이후에 이관 | 클라우드 경험 없음 → 위험 분리 |
| D4 | iframe 미사용. `<script>` 우선, npm은 그 다음 | 사용자 요구. 같은 소스에서 빌드 설정만 다름 |
| D5 | GitHub 공개는 **가장 마지막**. 소스만 올리고 타일 데이터는 올리지 않음 | 타일 1GB+, 파일당 100MB 제한 |
| D6 | GitHub에는 꼭 필요한 것만. 로컬 백엔드 서버가 필요 없는 구성이면 서버 코드는 올리지 않음 | 사용자 요구. 결정: 뷰어와 GIS 작업실 소스만 공개하고 서버는 별도 비공개 저장소로 분리했다 |
| D7 | 기존 `threeWithTiles`는 수정하지 않고 백업으로 유지. 새 작업은 `gis-viewer-kit/`에서 | 사용자 요구 |
| D8 | 서버는 Draco/KTX2 디코딩을 하지 않는다 | 데이터가 커지고 GPU 압축 이점이 사라짐. 현재 타일은 Draco+KTX2 **필수** |
| D9 | 사용자가 올린 타일셋의 압축 여부를 **자동 판별하고, 필요하면 브라우저에서 디코드**한다 (Draco, KTX2, Meshopt). 압축이 없는 데이터도 그대로 표시한다 | 사용자도 자기 데이터가 압축됐는지 모를 수 있음. 구현: 타일 파일 앞부분만 읽어 `extensionsUsed/Required` 확인(`kit/inspectContent.js`) + 로더는 세 디코더를 항상 등록해 두고 타일마다 필요할 때만 사용(비용 없음) + 필요한 디코더 파일이 없으면 미리 경고 |

## 5. 채택한 제안

| # | 제안 | 비고 |
|---|---|---|
| P1 | Java 21 + Spring Boot 3.x | 별도 저장소의 서버에서 사용 |
| P2 | 빌드 도구는 Maven (멀티모듈) | PC에 mvn 없음 → IntelliJ 내장 Maven 또는 Maven Wrapper 사용 |
| P3 | 서버는 `core` / `starter` / `app` 3단 | 실행형 앱과 라이브러리 제공을 한 코드로 (별도 저장소) |
| P4 | 로컬 파일 모드는 Chromium(Chrome/Edge) 우선 지원, 그 외 브라우저는 폴더 선택 input 폴백 | [02-architecture.md](02-architecture.md) 4절 |
